# E-Commerce Website Frontend

A simple and responsive e-commerce website for football boots.

## Features

* Product slider
* Multiple football boot products
* Product prices
* Shoe size selection
* Buy Now button
* Checkout form
* Responsive design

## Built With

* HTML
* CSS
* JavaScript

## Run Locally

Clone the repository:

```bash
git clone https://github.com/guddies378/e-commerce-website_frontend.git
```

Open the project folder and run `index.html` in your browser.

## Note

The checkout does not process real payments.
